3.3 Attachment Resolution & Constraints
────────────────────────────────────────────────────────────────────────────────

Forensic Discovery:
  • Endpoint /api/v0/chat/history_messages mengembalikan metadata lengkap
    file (id, file_name, file_size, token_usage, status).
  • TAPI endpoint /api/v0/file/download balikin HTML challenge meski status
    200 OK — butuh session cookie (ds_session_id) yang cuma ada di browser.
  • Bearer token doang gak cukup. Konfirmasi: file binary TIDAK BISA
    di-download otomatis via API.

Architectural Solution:
  • json_parser.py handle resolusi lokal via _find_local_file() —
    cek 4 lokasi: ./attachments/, ./, {base_dir}/attachments/, {base_dir}/
  • File gambar otomatis di-encode Base64 & dirender inline
  • File non-gambar dirender sebagai attachment card
  • User diarahkan lewat attachments/PENDING.md

7.1 Session API DeepSeek — Raw Response Keys
────────────────────────────────────────────────────────────────────────────────

{
  "chat_session": {
    "id", "title", "inserted_at", "updated_at",
    "model_type", "current_message_id", "version"
  },
  "chat_messages": [
    {
      "message_id", "parent_id", "role", "content",
      "files", "thinking_content", "search_results",
      "inserted_at", "model"
    }
  ],
  "cache_valid": false,
  "route_id": null
}

Catatan:
  • role UPPERCASE (USER, ASSISTANT)
  • inserted_at float epoch (Unix timestamp)
  • files[].id = "file-{uuid}" format, bukan file_id
  • search_results cuma muncul kalo search_enabled: true
  • thinking_content cuma muncul kalo thinking_enabled: true

7.3 Account Suspension Lessons Learned
────────────────────────────────────────────────────────────────────────────────

  • Pattern request berubah drastis (script vs human) → risk control trigger

  • Incremental backup (skip session tanpa update)


7.4 JavaScript Parse Error Cascade (Bugfix v2.2)
────────────────────────────────────────────────────────────────────────────────

Fenomena:
  Kurung kurawal `}` yang salah posisi di viewer.html (loadDistIndex)
  bikin SELURUH <script> gagal parse. Efeknya:
    • Markdown gak render
    • Sidebar kosong
    • Search gak jalan
    • Theme toggle gak ngefek
    • SEMUA fitur JS mati

Root cause:
  section.appendChild(el) dipanggil DI LUAR callback addEventListener,
  padahal harusnya DI DALAM. Akibatnya parser JS nemu `}` yang gak match,
  stop parsing, dan semua kode setelahnya gak jalan.

Lesson:
  • Browser JS parser (V8, SpiderMonkey) forgiving — error muncul di baris
    yang gak berhubungan.
  • Selalu cek Console (F12) buat Uncaught SyntaxError.
  • Auto-close bracket di editor = penyelamat.
