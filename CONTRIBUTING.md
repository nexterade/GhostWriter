# Contributing to GhostWriter

Terima kasih udah mau contribute! 👻

## 🐛 Report Bug

Buka Issue dengan info:
- Versi Python
- OS (Termux, Linux, macOS, Windows)
- Langkah reproduksi
- Error message lengkap

## 💡 Feature Request

Buka Issue dengan label enhancement.

## 🔧 Pull Request

1. Fork repo
2. Bikin branch (contoh: feat/nama-fitur)
3. Commit dengan pesan jelas
4. Push & buka PR

## 📏 Code Style

- Python: PEP 8
- Line length: 100
- Indent: 4 spasi
- Naming: snake_case untuk variable/function, PascalCase untuk class
